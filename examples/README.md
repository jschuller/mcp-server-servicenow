# Examples

- [`template/`](template/): copy it to start your own repository of ServiceNow skills.
- [`change-impact/`](change-impact/): two example skills (change impact, SLA definitions), with evals.
- [`incident-triage/`](incident-triage/): incident triage and trend reports (ITSM), with evals. It shipped inside the server until 0.9.0.

All are plain Agent Skills plus this server's [skill profile](../docs/skill-profile.md); the guide is [EXTENDING.md](../EXTENDING.md). They are not part of the wheel or the plugin: install them like any skill.
